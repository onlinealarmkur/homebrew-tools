# Timer for Homebrew

[timer-cli](https://github.com/onlinealarmkur/timer-cli) is a terminal countdown timer for macOS and Linux.

## Install

```sh
brew install onlinealarmkur/tools/timer-cli
```

## Upgrade

```sh
brew update
brew upgrade onlinealarmkur/tools/timer-cli
```
